# MacroFlow — Frontend

Frontend do **MacroFlow**, sistema de acompanhamento alimentar e corporal desenvolvido como projeto de TCC.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Chart.js
* SVG

## Funcionalidades

* Autenticação e cadastro
* Gerenciamento de alimentos e receitas
* Registro e histórico de consumo
* Metas nutricionais
* Acompanhamento corporal
* Recomendações alimentares
* Assistente de IA
* Interface responsiva

## Estrutura

```text
frontend/
├── html/
├── style/
├── script/
├── img/
└── README.md
```

## Integração

O frontend se comunica com a API REST do MacroFlow desenvolvida em **Java Spring Boot**, utilizando requisições HTTP e JSON.

A autenticação utiliza **JWT** para proteger os recursos da aplicação.

## Interface

A interface utiliza uma identidade visual baseada em **Frutiger Aero e Glassmorphism**, com foco em transparência, gradientes, elementos arredondados e responsividade.
